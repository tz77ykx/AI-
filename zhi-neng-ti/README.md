# Agent、工作流与MCP

本栏目用于理解 Agent 的基本组成、多模型协作方式、工作流设计和模型上下文协议。内容偏向技术原理与实践，不属于产品购买或基础使用的必读内容。

## 建议学习顺序

1. [构建智能体实用指南（中文）](gou-jian-zhi-neng-ti-shi-yong-zhi-nan.md)：先建立 Agent 的整体认识；
2. [基础多LLM工作流（中文）](ji-chu-de-duo-llm-ji-chu-gong-zuo-liu.md)：了解提示链、并行和路由等基本模式；
3. [构建高效的智能体（中文）](gou-jian-gao-xiao-de-zhi-neng-ti.md)：继续理解工作流与 Agent 的取舍；
4. [模型上下文协议正式发布（中文）](mo-xing-shang-xia-wen-xie-yi-zheng-shi-fa-bu.md)：了解 MCP 解决的问题；
5. [构建MCP客户端（中文）](gou-jian-mcp-ke-hu-duan.md)：需要动手实践时再阅读。
