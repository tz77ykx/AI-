# 完成第一个任务

这一页用一份简单笔记检查：Codex 能否读取你提供的材料、生成文件，以及按反馈修改结果。

开始前，先完成[安装与开通](an-zhuang-yu-kai-tong.md)。准备一个专门用于练习的文件夹，并放入一份不含个人隐私的笔记。笔记可以很短，也可以直接使用下面的示例。

## 第一步：准备练习材料

新建一个名为“首次任务练习”的文件夹，放入“练习笔记.txt”：

```text
本周准备做三件事：
1. 整理课程笔记，周三前完成。
2. 给读书小组准备一份讨论提纲，还没确定截止时间。
3. 检查已整理的资料链接是否能打开，周五前完成。
```

## 第二步：让 Codex 生成清单

在 Codex 中选择这个练习文件夹，新建任务并发送：

```text
请读取这个文件夹中的“练习笔记.txt”，整理成一份待办清单。

要求：
1. 只使用笔记中已有的信息，不要补写负责人或截止日期。
2. 没有截止日期的任务标注“待确认”。
3. 保存为同一文件夹中的“待办清单.md”。
4. 保留原始笔记，完成后告诉我生成了哪个文件。
```

完成时，应能在文件夹中找到“待办清单.md”。如果 Codex 询问是否允许读取或写入文件，先核对请求是否对应本次练习文件夹，再决定是否允许。

## 第三步：打开文件检查

* 清单是否有三件事，且没有遗漏或凭空增加事项？
* 周三、周五是否对应正确任务？
* 讨论提纲的截止时间是否标为“待确认”？
* 原始笔记是否仍在？

发现不对时，指出具体问题，让 Codex 修改“待办清单.md”，然后重新打开检查。

## 第四步：做一次小修改

继续发送：

```text
请把“待办清单.md”改成带复选框的列表，保持任务内容和日期不变。
```

再次打开文件，确认格式已更新。到这里，你已经走完“给材料 → 提要求 → 生成文件 → 检查 → 反馈修改”的完整过程。
