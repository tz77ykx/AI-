# 安装 CC Switch

本页只负责完成 CC Switch 软件的下载、安装和首次打开。安装完成后，暂时不要自行填写服务地址或个人密钥，后续会在“导入个人线路”教程中统一配置。

## 安装前确认

CC Switch 是免费、开源的软件。请只从以下官方渠道下载：

* [CC Switch 官方网站](https://ccswitch.io/)
* [CC Switch 官方 GitHub Releases](https://github.com/farion1231/cc-switch/releases)

官方GitHub仓库的所有者名称应为 `farion1231`，项目名称应为 `cc-switch`。任何要求单独购买CC Switch、向软件作者充值，或者索取账号密码的网站，都不属于官方安装流程。

支持的常用系统如下：

| 系统      | 最低要求                        | 本教程推荐方式      |
| ------- | --------------------------- | ------------ |
| Windows | Windows 10及以上，x64或ARM64     | 下载Windows安装包 |
| macOS   | macOS 12及以上，支持Intel和Apple芯片 | 下载macOS安装包   |

如果电脑系统低于上述要求，应先升级系统；不要从不明网站下载所谓的“兼容修改版”。

## Windows安装

### 第一步：确认电脑架构

绝大多数使用Intel或AMD处理器的Windows电脑选择普通Windows安装包即可。

如果不确定：

1. 打开Windows“设置”；
2. 进入“系统 → 系统信息”或“系统 → 关于”；
3. 查看“系统类型”；
4. 显示基于x64的处理器时，选择普通Windows安装包；
5. 显示基于ARM的处理器时，选择文件名中带有 `arm64` 的安装包。

### 第二步：下载安装包

1. 打开[官方 Releases 页面](https://github.com/farion1231/cc-switch/releases)；
2. 找到页面最上方标记为“Latest”的最新正式版本；
3. 点击或展开“Assets”下载文件列表；
4. 普通x64电脑下载名称类似于以下格式的文件：

`CC-Switch-v版本号-Windows.msi`

Windows ARM64设备选择文件名中明确带有 `arm64` 的对应安装包。

版本号会随更新变化，只要文件来自官方 Releases 页面即可，不需要与教程截图中的版本号完全相同。

普通用户建议选择 `.msi` 安装包，不建议优先使用Portable便携版。不要下载页面底部自动生成的 `Source code (zip)` 或 `Source code (tar.gz)`，它们是源代码，不是普通安装包。

### 第三步：完成安装

1. 下载完成后，双击 `.msi` 文件；
2. 按照安装窗口提示继续；
3. 安装完成后，在Windows开始菜单中搜索“CC Switch”；
4. 点击打开软件。

如果双击安装包后没有反应：

1. 右键点击安装包；
2. 选择“属性”；
3. 在“常规”页面找到“安全”；
4. 如果能够看到“解除锁定”，勾选并保存；
5. 重新运行安装包。

部分电脑不会显示“解除锁定”，这并不异常。如果安装程序仍然无法打开，不要关闭系统安全功能，也不要改用陌生网站的安装包，应保留报错截图并在客户群反馈。

### 第四步：确认Windows安装成功

同时满足以下情况，即表示CC Switch本身已经安装成功：

* 可以从开始菜单打开CC Switch；
* 主窗口能够正常显示；
* Windows任务栏通知区域能够看到CC Switch图标。

如果通知区域图标被折叠，可以点击任务栏右侧的向上箭头查看。只要主窗口可以正常打开，图标暂时没有直接显示不代表安装失败。

此时如果界面提示没有检测到Codex，也不代表CC Switch安装失败，只说明Codex运行环境尚未安装，继续阅读后续教程即可。

## macOS安装

### 第一步：下载安装包

1. 打开[官方 Releases 页面](https://github.com/farion1231/cc-switch/releases)；
2. 找到页面最上方标记为“Latest”的最新正式版本；
3. 点击或展开“Assets”下载文件列表；
4. 下载名称类似于以下格式的文件：

`CC-Switch-v版本号-macOS.dmg`

该macOS安装包用于官方支持的Intel和Apple芯片Mac。普通用户建议下载 `.dmg` 文件，不要下载 `Source code` 源代码压缩包。

熟悉Homebrew的用户也可以在终端执行：

```bash
brew install --cask cc-switch
```

### 第二步：完成安装

1. 双击已经下载的 `.dmg` 文件；
2. 在弹出的窗口中，将“CC Switch”拖入“应用程序”文件夹；
3. 打开访达；
4. 进入“应用程序”；
5. 双击“CC Switch”启动。

官方提供的macOS版本已经完成Apple代码签名和公证。只要安装包来自官方渠道，正常情况下可以直接打开。如果系统显示的开发者、文件来源或安全提示与官方信息不符，应停止安装并反馈，不要随意关闭macOS安全保护。

### 第三步：确认macOS安装成功

同时满足以下情况，即表示CC Switch本身已经安装成功：

* 可以从“应用程序”文件夹打开CC Switch；
* 主窗口能够正常显示；
* macOS菜单栏或程序坞能够看到CC Switch正在运行。

此时如果界面没有显示Codex，或者提示尚未安装对应工具，不属于CC Switch安装故障，后续安装Codex后再检查。

## 第一次打开后先不要做什么

为了避免配置错误，首次打开后暂时不要：

* 从网上复制陌生人的服务地址、API Key或Token；
* 导入群聊中公开传播的配置文件；
* 删除软件自动识别到的原有Codex配置；
* 随意开启本地代理、故障转移或其他高级功能；
* 把自己的CC Switch数据库、导出备份或配置文件发送给他人。

如果软件已经自动识别出旧配置，先保持原样，不要删除或覆盖，后续按照线路导入教程处理。

完成安装后，关闭无关窗口，保留CC Switch即可。个人线路将在后续步骤中导入。

## 常见问题

### 下载页面有很多文件，应该选哪个？

Windows普通x64用户选择文件名以 `Windows.msi` 结尾的安装包；Windows ARM64用户选择带有 `arm64` 标识的对应文件；macOS普通用户选择文件名以 `macOS.dmg` 结尾的安装包。

不要下载Portable、Linux、Source code或其他系统的文件，也不要根据其他网站转载的旧版本号寻找安装包。

### 为什么软件打开后没有Codex？

CC Switch和Codex是两个不同的软件。安装CC Switch只完成了配置工具的安装；电脑还需要安装必要运行环境和Codex，之后才能导入线路并使用。

### 软件提示可以更新，要不要更新？

可以通过CC Switch内置更新提示更新，也可以进入“设置 → 关于”手动检查。更新前先确保重要配置已经备份。

### 是否需要登录CC Switch账号？

安装CC Switch本身不等于登录AI账号，也不会自动获得套餐额度。是否需要导入个人线路，以后续交付教程为准。

### 反馈问题时可以发送什么？

可以发送安装报错、系统版本和软件界面截图，但必须遮住API Key、Token和其他个人密钥。不要直接发送CC Switch数据库、导出备份或完整配置文件。

## 本页完成标准

完成本页后，只需要确认：

1. CC Switch来自官方渠道；
2. 软件已经安装；
3. 主窗口可以正常打开；
4. 没有把个人密钥或完整配置发送给他人。

完成以上内容后，再继续安装Codex所需的运行环境。
