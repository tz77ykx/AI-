# 前端与网站开发

本栏目收录使用 Codex 完成网站与前端界面的实战方法，重点不是记忆某个框架的命令，而是建立可以重复执行的工作流：

**明确目标与内容 → 提供设计参考 → 固化设计规则 → 实现页面 → 浏览器视觉检查 → 测试与发布。**

你可以从这里学习：

* 如何把模糊的审美要求转化为可以执行和检查的设计说明；
* 如何根据截图、网站或设计稿实现响应式页面；
* 如何复用项目已有的组件和设计系统；
* 如何在真实浏览器中检查桌面端、移动端和交互状态；
* 如何根据具体偏差迭代页面，而不是反复推倒重做；
* 如何处理图片、动效、性能、部署和验收。

没有设计背景也可以从页面目标和参考开始。不要先追求工具数量，先学会定义结果、保留约束并检查实现。
