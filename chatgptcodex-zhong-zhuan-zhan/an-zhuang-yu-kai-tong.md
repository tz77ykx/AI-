# 安装与开通

适用于已经购买 Codex 服务、准备首次使用或恢复本机配置的用户。完成后，应能正常发起任务、查看用量，并保存一个可检查的结果文件。

## 先确认你从哪一步开始

{% tabs %}
{% tab title="已经由交付人员装好" %}

1. 按[最终验收](aidut-zhong-zhuan-yu-cc-switch-pei-zhi.md#verify)确认线路和用量显示。
2. [完成第一个任务](wan-cheng-di-yi-ge-ren-wu.md)，检查产物是否符合要求。
3. 进入[日常使用](ru-men-jiao-cheng/README.md)。

{% endtab %}
{% tab title="需要安装或恢复" %}

1. 确认购买时指定的设备与系统，并按交付指导准备 Codex 客户端。
2. [安装 CC Switch](an-zhuang-cc-switch.md)：按自己的 Windows 或 macOS 系统操作。
3. 需要了解工具关系时，阅读[CC Switch 是什么](cc-switch-shi-shen-me-you-shen-me-yong.md)。
4. 已有官方账号且需要保留登录和会话历史时，按[保留官方登录与会话历史](cc-switch-zeng-qiang-gong-neng.md)的顺序配置。
5. [配置个人线路](aidut-zhong-zhuan-yu-cc-switch-pei-zhi.md#configure)，并[配置用量查询](aidut-zhong-zhuan-yu-cc-switch-pei-zhi.md#quota-setup)。
6. [完成验收](aidut-zhong-zhuan-yu-cc-switch-pei-zhi.md#verify)，再[完成第一个任务](wan-cheng-di-yi-ge-ren-wu.md)。

{% endtab %}
{% endtabs %}

已有 AIDUT 卡、只是缺少用量显示时，直接使用[原卡开通用量显示](aidut-zhong-zhuan-yu-cc-switch-pei-zhi.md#existing-quota)，无需重复新建。

## 完成检查

* Codex 能正常回应测试任务。
* 用量页面能显示今日、本周、本月额度。
* 能打开本次任务生成的文件，并核对内容。

**下一步：**[日常使用](ru-men-jiao-cheng/README.md)

**没有成功：**[问题排查](wen-ti-pai-cha.md)
