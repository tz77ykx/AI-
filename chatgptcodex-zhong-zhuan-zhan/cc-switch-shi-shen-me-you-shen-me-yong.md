# CC Switch 是什么？有什么用？

CC Switch 是一个开源的桌面配置管理工具，可以集中管理 Codex、Claude Code、Gemini CLI 等 AI 开发工具所使用的服务配置。

在这套交付流程中，可以把它简单理解为：

**CC Switch 负责保存和切换线路，Codex 负责真正执行任务。**

CC Switch 本身不提供 AI 模型、套餐额度或官方账号，也不是套餐销售平台。你购买的套餐决定可以使用多少额度；CC Switch 只是帮助电脑正确连接到对应服务。

## 先认识几个名词

| 名词    | 本文中的含义                         |
| ----- | ------------------------------ |
| Codex | 在电脑上读取文件、修改项目和执行任务的 AI 工具      |
| 中转站   | 为 Codex 提供第三方模型接入和套餐额度的服务      |
| 线路    | 一组可以使用的服务配置，通常包含服务地址、个人密钥和模型设置 |
| 个人密钥  | 识别客户身份并计算套餐用量的使用凭证             |
| 镜像站   | 直接通过浏览器登录使用的第三方 AI 网页          |

CC Switch 是独立的配置工具，不代表套餐服务商，也不会改变套餐原有的额度规则。

## 为什么需要 CC Switch？

如果不使用配置工具，更换线路时通常需要手动寻找配置文件、修改服务地址、填写密钥并检查格式。对于不熟悉电脑配置的用户，这些步骤很容易出错。

使用 CC Switch 后，常用操作可以集中在同一个界面完成：

* 保存已经购买的线路配置；
* 在不同线路之间切换；
* 管理服务地址、模型和个人密钥；
* 检查配置是否完整；
* 在支持的情况下测试线路连通性；
* 备份和恢复本机配置；
* 减少反复修改配置文件造成的错误。

## 它在整个使用流程中的位置

使用关系可以理解为：

**购买套餐 → 获得个人线路信息 → 导入 CC Switch → 启动 Codex → 开始使用**

| 项目        | 负责什么             |
| --------- | ---------------- |
| 套餐或线路     | 提供模型访问、额度和有效期    |
| CC Switch | 保存、导入和切换线路配置     |
| Codex     | 读取配置，并在电脑上执行实际任务 |

因此，CC Switch 不是 Codex 的替代品，两者需要配合使用。

## 哪些用户需要安装？

以下用户通常需要使用 CC Switch：

* 购买 Codex 中转站套餐；
* 需要在多条已经购买的线路之间切换；
* 不想手动修改配置文件；
* 更换套餐后需要更新服务地址或个人密钥；
* 希望以后能够自行完成基础配置和排查。

\*\*如果只购买 ChatGPT 网页版镜像站套餐，不需要安装 CC Switch，直接通过浏览器登录即可。\*\*只有同时购买并使用 Codex 中转站套餐时，才需要按照后续教程安装。

## CC Switch 不能解决什么？

CC Switch 只是配置管理工具，不能：

* 创建或赠送套餐额度；
* 绕过套餐的小时、每日、每周或有效期限制；
* 保证线路始终可用；
* 修复电脑系统、网络或其他无关软件故障；
* 恢复已经丢失的聊天记录和生成文件；
* 代替 Codex 完成具体任务；
* 把第三方线路变成 OpenAI 官方订阅。

同一套餐达到额度限制后，反复导入或切换它的配置不会增加额度，应等待恢复或升级套餐。如果另外购买了一条独立线路，则按照新线路自己的额度和有效期计算，不能把两条线路的数字混在一起。

## 关于个人密钥

个人密钥相当于线路的使用凭证，应当像密码一样保管。

* 不要把完整密钥发布到群聊、公开网页、代码仓库或截图中；
* 不要把自己的线路配置分享给其他人；
* 导入配置时，只使用购买后单独收到的信息；
* 更换电脑或重装系统后，需要重新导入配置；
* 怀疑密钥泄露时，应停止继续分享，并联系售后处理或更换；
* 向客户群反馈问题时，可以发送报错界面，但必须遮住完整密钥。

CC Switch 会在本机保存配置，因此不要把电脑中的 CC Switch 数据库、配置文件或备份文件随意发送给他人。使用公共电脑或多人共用设备时，不建议保存个人线路配置。

## 下一步

了解 CC Switch 的作用后，再根据自己的电脑系统进入对应部署教程，依次完成：

1. 安装必要运行环境；
2. 安装 CC Switch；
3. 安装 Codex；
4. 导入个人线路；
5. 重新打开 Codex并完成首次连通测试。
