# ChatGPT（Codex）中转站

中转站为 Codex 提供第三方接入和部署服务，适合需要在电脑上完成编程、文件处理、项目修改和可执行任务的用户。它不是 OpenAI 官方订阅，使用请求会经过第三方服务。

## 适合哪些需求

* 使用 Codex 完成编程、调试、文件处理或项目修改；
* 希望按照固定周期购买额度，并获得首次安装和基础教学；
* 需要多模型、API 接入或生产环境时，选择对应的多模型或按量方案。

## 建议阅读顺序

1. 购买前先阅读[中转站购买说明](zhong-zhuan-zhan-gou-mai-shuo-ming.md)，确认额度限制、有效期和售后范围；
2. 开通后按照[入门教程](ru-men-jiao-cheng/)完成基础设置和使用；
3. 熟悉基础操作后，再按需阅读[Codex常用技能与插件](codex-chang-yong-ji-neng-yu-cha-jian.md)。

## 使用前注意

不同套餐采用不同的额度和恢复规则，不能只比较页面显示的额度数字。重要代码、对话和生成文件应由使用者自行保存；未公开研究、客户资料、账号密码等高度敏感信息不应直接上传。
