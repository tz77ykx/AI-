# ChatGPT（Codex）中转站

中转站为 Codex 提供第三方接入和部署服务，适合需要在电脑上完成编程、文件处理、项目修改和可执行任务的用户。它不是 OpenAI 官方订阅，使用请求会经过第三方服务。

## 适合哪些需求

* 使用 Codex 完成编程、调试、文件处理或项目修改；
* 按 30 天周期购买额度，并获得首次安装和基础教学；
* 希望在购买前明确查看日限额、周限额和 30 天总限额。

当前销售的套餐和价格统一列在[中转站购买说明](zhong-zhuan-zhan-gou-mai-shuo-ming.md)中，不提供多模型按量方案或生产环境临时报价。

## 建议阅读顺序

1. 购买前先阅读[中转站购买说明](zhong-zhuan-zhan-gou-mai-shuo-ming.md)，确认额度限制、有效期和售后范围；
2. 开通后按照[入门教程](ru-men-jiao-cheng/)完成基础设置和使用；
3. 需要自行检查或恢复线路时，阅读[AIDUT 中转与 CC Switch 配置](aidut-zhong-zhuan-yu-cc-switch-pei-zhi.md)；需要保留官方登录或统一会话历史时，再阅读[CC Switch 增强功能](cc-switch-zeng-qiang-gong-neng.md)。

## 使用前注意

当前套餐同时存在日限额、周限额和 30 天总限额，选择时应同时查看三项限制。重要代码、对话和生成文件应由使用者自行保存；未公开研究、客户资料、账号密码等高度敏感信息不应直接上传。
