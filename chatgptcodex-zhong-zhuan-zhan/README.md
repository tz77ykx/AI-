# Codex 电脑任务

为 Codex 提供第三方接入和部署服务，帮助你在电脑上完成编程、调试、文件处理和项目修改。套餐按 30 天周期提供额度，并包含购买时指定设备的首次安装和基础教学。

## 从这里开始

1. **还没购买：**[查看套餐与购买](zhong-zhuan-zhan-gou-mai-shuo-ming.md)，一起比较日限、周限和 30 天总限。
2. **已经购买：**[安装与开通](an-zhuang-yu-kai-tong.md)，根据设备和当前安装状态进入下一步。
3. **已经能用：**[日常使用](ru-men-jiao-cheng/README.md)，查看基本设置、语音输入和用量入口。
4. **遇到问题：**[问题排查](wen-ti-pai-cha.md)，按错误和症状定位。

## 用起来之后

先[完成第一个任务](wan-cheng-di-yi-ge-ren-wu.md)，确认能生成、打开和检查文件。需要目标模式、GitHub 或网站开发时，再进入[实战教程](../shi-zhan-jiao-cheng/README.md)。

## 使用前了解

本服务不是 OpenAI 官方订阅，使用请求会经过第三方服务。当前销售范围以[套餐与购买](zhong-zhuan-zhan-gou-mai-shuo-ming.md)为准，不提供多模型按量方案或生产环境临时报价。

当前套餐同时存在日限额、周限额和 30 天总限额，选择时应同时查看三项限制。重要代码、对话和生成文件应由使用者自行保存；未公开研究、客户资料、账号密码等高度敏感信息不应直接上传。
