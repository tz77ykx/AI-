# 入门教程

## 1 这套教程统一使用 Codex

打开 ChatGPT 桌面端后，你会看到 ChatGPT 和 Codex 两个入口。为了减少选择和学习成本，这套教程统一使用 Codex。

无论你要写代码、整理资料、分析文件、写文档还是制作网页，都先进入 Codex。Codex 不只能做编程任务，OpenAI 官方也明确说明：已经使用 Codex 处理非编程工作的人，可以继续留在 Codex。[查看 OpenAI 官方说明](https://learn.chatgpt.com/docs/get-started-with-work)

这不代表 Work 不能完成这些任务，也不代表 Codex 在所有场景里都更强。只是对刚开始使用的人来说，先把所有任务放在同一个入口，比反复判断该用 Work 还是 Codex 更简单。

如果以后你的界面提供 Work Cloud，而且你明确需要任务在关闭电脑后继续运行，或者要从网页、移动端继续处理同一个 Work 任务，再考虑使用它。现在不需要专门学习 Work。

这是一篇 Codex 桌面端入门教程。下面只介绍桌面端界面和操作，不要求你使用命令行。

## 2 用语音输入 Prompt

Prompt 经常比普通聊天消息长。如果全部靠键盘输入，会把很多时间消耗在打字上。建议使用语音输入，把想法先完整说出来，再检查和修改文字。

这里推荐两个软件：

* [闪电说](https://shandianshuo.cn/)：截至 2026-08-22，官网提供 macOS 和 Windows 版本。
* [豆包输入法](https://srf.doubao.com/)：截至 2026-08-22，官网提供 macOS 版本，Windows 版仍标为“敬请期待”。

如果你使用 macOS，建议把两款软件分别连续使用一周，再根据自己的实际体验选择。不要先预设哪一款一定更好。

如果你使用 Windows，目前先使用闪电说；等豆包输入法正式提供 Windows 版本后，再决定是否补充体验。

不需要先研究复杂的使用教程。安装后，直接在日常使用 Codex 时尝试语音输入即可。

## 3 设置教程

### 3.1 常规

按下面的清单逐项设置。复选框只用于标记“是否已经完成”，实际开关状态以每项文字说明为准。

#### 权限

* [ ] 默认权限：打开。
* [ ] 完全访问权限：使用的前 1 个月保持关闭；满 1 个月后，再根据个人实际体验决定是否开启。

#### 常规

* [ ] 默认文件打开目标：Default app。
* [ ] 语言：自动检测。
* [ ] 在菜单栏中显示：打开。
* [ ] 底部面板：打开。
* [ ] 默认终端位置：底部。
* [ ] 运行时防止系统休眠：打开。
* [ ] 速度：快速。
* [ ] 建议提示：打开。
* [ ] Plugins：打开。

#### 编辑器

* [ ] 显示上下文窗口使用情况：关闭。
* [ ] 发送快捷键：按 Enter 键。
* [ ] 跟进行为：排队。

#### 弹出窗口

* [ ] 弹出窗口快捷键：禁用。
* [ ] 默认使用独立聊天：打开。

#### 通知

* [ ] 轮次完成通知：仅当应用失焦时。
* [ ] 启用权限通知：打开。
* [ ] 启用问题通知：打开。
