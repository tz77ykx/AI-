# 模型与系统卡

本栏目收录系统卡和模型资料，用于理解具体模型的设计目标、能力说明、评测结果、限制与安全边界。

## 建议阅读顺序

1. 阅读[Claude Mythos Preview 系统卡（中文）](xi-tong-ka-system-cardclaude-mythos-preview.md)，了解一份系统卡如何说明模型能力、安全评测和适用边界；
2. 需要核对术语、原始表述或引用时，再打开对应的[英文原文](system-card-claude-mythos-preview.md)；
3. 阅读时区分“发布时披露的信息”和“当前产品的实时状态”。

系统卡反映的是对应版本发布时披露的信息，不能直接代替当前产品页面和实时使用结果。
