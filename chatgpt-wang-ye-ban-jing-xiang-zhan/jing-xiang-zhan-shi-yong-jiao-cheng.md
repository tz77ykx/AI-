# 镜像站使用教程

本教程只介绍通用操作。页面布局、模型名称和入口数量可能调整，请以实际页面为准。

## 一、注册并登录

1. 打开[主注册入口](https://gpt.ai0.cn/pastel#/register?i=7VFjrj)；
2. 使用常用的QQ邮箱完成注册；
3. 注册完成后，将注册所用的QQ邮箱发给我；
4. 如果主入口临时无法打开，可尝试[备用登录入口](https://gpt.ai1.bar/pastel/#/login)；
5. 镜像站账号不是官方账号，不要直接提交官方账号密码；
6. 妥善保存自己的登录信息，避免因忘记账号造成历史记录无法找回；
7. 只发送注册邮箱，不要发送密码、验证码或其他敏感信息。

## 二、兑换并激活套餐

登录后，先在完整页面中找到左上角的“兑换码兑换”。

![兑换码兑换入口位置](https://1747313157-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FfhJ3MQlSexscjstFyuJB%2Fuploads%2Fgit-blob-4d6aa9ad2e854014b49e4e3e17db4e321b1aeed8%2Fjing-xiang-zhan-dui-huan-ma-ru-kou.jpg?alt=media)

1. 点击页面左上角的“兑换码兑换”；
2. 在弹窗中输入购买后收到的兑换码；
3. 确认兑换码无误后，点击“立即兑换”，不要连续重复提交。

![输入兑换码并立即兑换](https://1747313157-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FfhJ3MQlSexscjstFyuJB%2Fuploads%2Fgit-blob-8ad0d3d623fc7cf73e7f935126a239432c429b65%2Fjing-xiang-zhan-dui-huan-tan-chuang.jpg?alt=media)

套餐生效规则：兑换后的套餐会立即生效。如果账号中还有尚未使用完的套餐，原套餐会在本次兑换套餐到期后继续使用。

兑换完成后，关闭弹窗并检查页面显示的套餐类型、有效期和使用量是否正确。如显示异常，请保留兑换码和页面截图，在客户群反馈。

## 三、选择普通入口或PRO入口

普通版用户从常规入口进入，选择页面当前开放的模型使用。

PRO版用户主要有两种使用途径：

* 方式一：首页中的PRO车队；
* 方式二：左侧的PRO专用入口。

![PRO车队与PRO专用入口位置](https://1747313157-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FfhJ3MQlSexscjstFyuJB%2Fuploads%2Fgit-blob-3755d880dc99019a419d32b9057a696e64535dfc%2Fjing-xiang-zhan-pro-ru-kou.jpg?alt=media)

这两个入口可以互相补充。如果一个入口暂时无法使用，可以返回入口页面尝试另一个PRO入口。

不同入口不一定共享相同的模型列表、功能、额度和聊天记录。切换入口前应查看当前页面，不要把入口切换理解为聊天记录和使用状态的无缝迁移。

## 四、选择模型

1. 进入对话页面后，查看当前可选模型；
2. 根据任务选择合适的普通模型或PRO模型；
3. 如果某个模型暂时不可用，可以切换其他模型或入口；
4. 可用模型会随平台调整，具体以页面实时显示为准。

不要只根据旧教程中的模型名称判断当前功能。

## 五、常见功能

平台可能提供以下功能，实际开放情况以页面为准：

* 普通文本对话、写作、翻译和资料整理；
* 上传PDF、图片等文件进行分析；
* 联网查询；
* GPTs、插件或其他工具；
* 普通模型与PRO模型切换；
* 多个PRO入口之间切换。

如果页面暂时没有某项功能，可能是对应模型、入口或平台状态发生了调整。

## 六、额度与历史记录

* 300/24h或500/24h是平台显示的额度标识，实时剩余额度以当前页面为准；
* 不同模型、工具和入口的消耗方式可能不同；
* 切换入口后，应重新查看该入口显示的额度；
* 重要回答应复制到本地文档；
* 重要文件应保留原始副本；
* 不要把网页聊天记录当作唯一备份；
* 更换账号、切换服务入口或平台调整时，原有记录可能无法继续显示。

## 七、遇到问题先这样排查

### 页面打不开或一直加载

1. 刷新页面；
2. 重新登录；
3. 检查本机网络；
4. 稍后再次尝试。

### 某个模型无法使用

1. 返回模型列表；
2. 切换其他当前可用模型；
3. PRO用户可切换其他PRO入口；
4. 若多个入口均不可用，再在客户群反馈。

### 对话响应慢或提交失败

1. 等待当前请求结束，避免连续重复提交；
2. 新建对话后重试；
3. 切换模型或入口；
4. 记录出现问题的时间、入口和模型，并将截图发到客户群。

## 八、反馈问题时请一次性提供

* 问题截图；
* 出现问题的大致时间；
* 使用的入口；
* 使用的模型；
* 当前页面显示的剩余额度；
* 已经尝试过的排查步骤。

不要发送账号密码、验证码或其他敏感信息。

能先通过文字和截图判断的问题，会先协助排查；需要远程操作、重新部署，或者涉及设备和网络的问题，按实际情况处理。

## 九、使用边界

镜像站是第三方网页服务，不是官方账号或官方客户端。对话和上传文件会经过第三方平台处理，无法承诺数据的保存期限、删除机制或长期可恢复性。

模型、入口和功能会随平台状态调整，以页面实时显示为准。涉及个人隐私、未公开研究、商业机密或客户资料时，不建议直接上传原始内容；确需使用时，应先匿名化和脱敏。
