# 网页聊天服务

通过 ChatGPT 网页镜像服务完成日常问答、学习、写作、翻译和资料整理。适合希望打开网页直接使用、无需自行处理官方账号环境的用户。

## 从这里开始

1. **还没购买：**[查看套餐与购买](jing-xiang-zhan-gou-mai-shuo-ming.md)，确认价格、额度、有效期和服务范围。
2. **已经购买：**[注册与开通](zhu-ce-yu-kai-tong.md)，完成注册、兑换与生效检查。
3. **已经能用：**[日常使用](jing-xiang-zhan-shi-yong-jiao-cheng.md#models)，查看模型、功能、额度和内容保存。
4. **遇到问题：**[问题排查](wen-ti-pai-cha.md)，按当前症状查找操作。

## 当前维护入口

登录镜像站后，**所有 ChatGPT 相关服务统一从“ChatGPT 车队”进入**。页面中显示的 Pro、Plus、Team 及其他 ChatGPT 服务，都以“ChatGPT 车队”为唯一维护入口；实际能够使用哪些服务，以所购套餐和页面实时显示为准。

“PRO 专用入口”“新站入口”以及其他历史 ChatGPT 入口均已停止维护，不再作为备用入口，也不再纳入使用教程、故障排查和售后支持范围。

## 使用前了解

这是第三方网页服务，能够使用的功能可能与官方服务不同，并会随平台调整。重要回答、聊天内容和文件应及时保存到本地。
