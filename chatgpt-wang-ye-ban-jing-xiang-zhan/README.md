# ChatGPT（网页版）镜像站

镜像站是通过第三方网页使用 AI 功能的方案，适合希望打开网页后直接使用、无需自行处理官方账号环境的用户。它不是官方账号，也不等同于官方客户端。

## 当前维护范围

登录镜像站后，**所有 ChatGPT 相关服务统一从“ChatGPT 车队”进入**。页面中显示的 Pro、Plus、Team 及其他 ChatGPT 服务，都以“ChatGPT 车队”为唯一维护入口；实际能够使用哪些服务，以所购套餐和页面实时显示为准。

“PRO 专用入口”“新站入口”以及其他历史 ChatGPT 入口均已停止维护，不再作为备用入口，也不再纳入使用教程、故障排查和售后支持范围。即使页面中仍能看到这些旧入口，也不要继续使用。

## 适合哪些需求

* 日常问答、学习辅助、写作、翻译和资料整理；
* 希望直接在网页中使用，不需要程序接入；
* 能够接受第三方平台与官方服务之间的功能差异和平台调整。

## 建议阅读顺序

1. 购买前先阅读[镜像站购买说明](jing-xiang-zhan-gou-mai-shuo-ming.md)，确认套餐、额度、有效期和售后范围；
2. 开通后按照[镜像站使用教程](jing-xiang-zhan-shi-yong-jiao-cheng.md)完成注册、兑换和基础设置；
3. 遇到问题时，先按照使用教程中的排查步骤处理，再在客户群反馈。

## 使用前注意

对话和上传文件会经过第三方平台处理。不要上传账号密码、密钥、身份证件、未公开研究数据、客户隐私或其他高度敏感信息；重要回答、聊天内容和文件应及时保存到本地。
